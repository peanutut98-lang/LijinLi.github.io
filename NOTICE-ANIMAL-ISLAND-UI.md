# animal-island-ui attribution

This non-commercial personal website adapts design tokens and visual patterns from
[animal-island-ui](https://github.com/guokaigdg/animal-island-ui), created by
guokaigdg. The referenced design system is licensed under the Creative Commons
Attribution-NonCommercial 4.0 International license (CC BY-NC 4.0).

No React source code or original illustration assets from the component library
are bundled into this Jekyll website. The local implementation in
`_sass/layout/_animal_island.scss` recreates selected design-system conventions
for the site's existing HTML structure.
