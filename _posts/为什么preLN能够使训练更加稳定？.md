我们先不讲“稳定的残差梯度通道”这种抽象说法，只用你已经掌握的两件事：

1. 梯度是偏导数，告诉参数应该怎么改。
2. 参数更新量等于“学习率 × 梯度”。

公式是：
$$
w_{\text{新}}=w_{\text{旧}}-\eta\frac{\partial L}{\partial w}
$$
这里
$$
\eta
$$
是学习率。

先搞清楚 warm-up 在防什么。模型刚开始训练时，所有参数都是随机的，因此最初几步算出来的梯度可能变化很剧烈，例如：

```
第1步梯度：20
第2步梯度：-15
第3步梯度：10
```

如果一开始就使用目标学习率 0.1，参数更新量是：

```
第1步：-0.1 × 20  = -2
第2步：-0.1 × -15 = +1.5
第3步：-0.1 × 10  = -1
```

参数会被来回大幅修改，模型可能直接训练崩掉。

Warm-up 的做法是：刚开始先用很小的学习率，例如 0.001：

```
第1步：-0.001 × 20  = -0.02
第2步：-0.001 × -15 = +0.015
第3步：-0.001 × 10  = -0.01
```

虽然梯度暂时很乱，但参数不会被改得太猛。等模型逐渐稳定，再把学习率提高到目标值。

所以一定要先记住：

> **Warm-up 主要不是解决梯度太小，而是防止训练刚开始时，不稳定的梯度配上较大的学习率，导致参数被改得太猛。**

接下来只看 Pre-LN：
$$
y=x+F(\operatorname{LN}(x))
$$
这里的输出由两部分组成：

```
原来的 x
+
注意力层产生的新信息
```

对 \(x\) 求偏导：
$$
\frac{\partial y}{\partial x} = 1+ \frac{\partial F(\operatorname{LN}(x))}{\partial x}
$$
假设模型刚开始训练，注意力支路还很乱。这一部分的梯度可能是 0.02：
$$
\frac{\partial F(\operatorname{LN}(x))}{\partial x}=0.02
$$
那么总梯度是：

\[ 1+0.02=1.02 \]

下一次它可能变成 \(-0.03\)，总梯度则是：

\[ 1-0.03=0.97 \]

虽然注意力支路的梯度在变化，但因为外面一直有一个来自原始 \(x\) 的 \(1\)，总梯度仍然在 1 附近：

```
支路梯度： 0.02  → 总梯度：1.02
支路梯度：-0.03  → 总梯度：0.97
支路梯度： 0.01  → 总梯度：1.01
```

这就是所谓的“梯度比较稳定”。不是梯度完全不变，而是它有一个稳定的基础值 1，不完全由随机初始化的注意力支路决定。

Post-LN 是：
$$
y=\operatorname{LN}(x+F(x))
$$
虽然里面也有 \(x+F(x)\)，但是相加之后还要经过 LayerNorm。反向传播时，梯度必须经过 LayerNorm：
$$
\frac{\partial y}{\partial x} = \frac{\partial\operatorname{LN}}{\partial(x+F(x))} \left( 1+\frac{\partial F(x)}{\partial x} \right)
$$
注意，那个 \(1\) 也被前面的 LayerNorm 偏导乘上了。假设 LayerNorm 这一段传回来的倍率是 0.1：
$$
0.1\times(1+0.02)=0.102
$$


如果另一层的倍率暂时是 3：

\[ 3\times(1-0.03)=2.91 \]

不同层收到的梯度就可能差别很大：

```
某一层：0.102
另一层：2.91
```

这时如果一开始就使用较大的学习率，有的层几乎不动，有的层却可能改得太猛。因此要用较长的 warm-up，先把学习率压低。

Pre-LN 中，原始 \(x\) 的偏导 1 不需要先乘上末尾 LayerNorm 的偏导，所以梯度通常更容易保持在合理范围。既然最初几步没有那么容易出现剧烈更新，学习率就可以更快升到目标值，甚至在某些训练设置中不做 warm-up。

完整的因果关系是：

```
Pre-LN 把 x 放在 LN 和注意力层外面
→ 对 x 求偏导时直接得到一个 1
→ 反向传播不完全依赖随机的注意力支路
→ 训练初期各层的梯度通常更容易控制
→ 不太需要用很小的学习率保护很多步
→ warm-up 可以很短，有时可以省掉
```

因此，“Pre-LN 的 warm-up 可极短或省掉”不是说 Pre-LN 改变了学习率，而是说：

> **Pre-LN 让训练刚开始时的梯度没那么危险，所以不需要长时间用很小的学习率保护参数。**

不过“可以省掉”不是绝对保证。模型规模、优化器、初始化方法和目标学习率不同，有些 Pre-LN 模型仍然会使用 warm-up，只是通常没有 Post-LN 那么依赖它。
